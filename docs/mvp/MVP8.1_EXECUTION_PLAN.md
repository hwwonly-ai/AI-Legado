# MVP 8.1 角色侧音色选择执行方案

## 1. 目标

MVP8.1 在 MVP8 音色库能力之后实现“从角色侧选择音色”：用户在书籍角色列表或角色编辑页中，为当前角色打开轻量音色选择器，选择阿里云或豆包中文音色。

职责边界：

- MVP8：从音色列表出发，把音色分配给角色、书籍旁白/对白或龙套。
- MVP8.1：从角色出发，只给当前角色选择音色。

## 2. 依赖

- 依赖 MVP8 的阿里云 / 豆包中文音色库。
- 依赖 MVP7 的书籍级角色结构和角色编辑页。
- 不新增数据库表，不升级数据库版本。

## 3. 范围

包含：

- 在角色列表或角色编辑页增加“选择音色”入口。
- 替代手动输入自定义音色 ID 的主要操作路径。
- 打开轻量音色选择器，选择后写入当前书当前角色。
- 支持搜索、试听、选择和清空自定义音色。
- 支持阿里云和豆包，不支持其他 TTS。

不包含：

- 不做批量分配。
- 不设置书籍旁白 / 默认对白。
- 不管理 8 个龙套的音色入口；龙套音色仍在 MVP8 音色管理中处理。
- 不新增音色库数据。
- 不修改 AI Segment、角色分类或自动归档逻辑。

## 4. 数据与写入

音色选择结果按书籍级隔离：

- 写入当前书当前角色：`BookReadAloudRole.voices[ttsEngine] = requestValue`。
- 同一角色在同一 Provider 下只能有一个自定义音色，后一次选择覆盖前一次。
- 同一个音色可以被多个角色选择。
- 不同书籍的同名角色互不影响。

请求参数：

- 阿里云：`voice = requestValue`。
- 豆包：`voice_type = requestValue`。

## 5. UI 设计

角色编辑页音色区域：

```text
音色
( ) 跟随同属性龙套
( ) 跟随书籍对白
( ) 自定义  [ 温柔淑女 ]  选择  清空
```

轻量音色选择器：

```text
┌────────────────────────────────────────────┐
│ 选择角色音色              [豆包2.0 ▼]  🔍 │
├────────────────────────────────────────────┤
│ 温柔淑女                                  │
│ 场景：通用场景       已分配：王丽  试听 选择│
├────────────────────────────────────────────┤
│ 成熟大叔                                  │
│ 场景：旁白场景       未分配        试听 选择│
└────────────────────────────────────────────┘
```

交互：

- 默认 Provider 使用当前朗读 Provider；仅显示阿里云和豆包。
- 当前 Provider 不支持时，禁用选择入口并提示“当前 TTS 暂不支持音色选择”。
- 搜索支持音色名称和声音属性。
- UI 显示 `displayName`、`voiceProperty`、已分配 `roleName`。
- UI 不显示请求参数值。
- 点击“试听”使用 MVP8 的试听文本配置。
- 点击“选择”后关闭选择器，并回填当前角色音色。
- 点击“清空”后删除当前角色在该 Provider 下的自定义音色，回退默认音色规则。

## 6. 缓存关系

沿用 MVP7 / MVP8 测试期策略：

- 保存或清空角色音色后，清理当前书当前章节音频缓存。
- 不清 AI Segment 缓存。
- 不清规则 Segment 缓存。
- 正式精确缓存失效留到 MVP10。

## 8. 验收用例

- 从角色编辑页点击“选择音色”可以打开轻量音色选择器。
- 选择阿里云音色后，角色朗读时使用 `voice = requestValue`。
- 选择豆包音色后，角色朗读时使用 `voice_type = requestValue`。
- 同一个音色可以被多个角色选择。
- 同一角色再次选择其他音色后，新音色覆盖旧音色。
- 清空角色自定义音色后，角色回退默认音色规则。
- 不同书籍同名角色的音色互不影响。
- 当前 Provider 不是阿里云或豆包时，选择入口不可用。

## 9. 完成定义

- 角色侧可通过音色列表选择自定义音色。
- 不再要求用户手动输入自定义音色 ID 作为主要路径。
- 复用 MVP8 音色库和试听文本配置。
- 音色选择结果按书籍级隔离。
- 不新增数据库表、不升级数据库版本。
- 静态检查通过，`./gradlew :app:assembleDebug` 通过。
